# Анализ исходных архивов Hikvision

Аудит выполнен без запуска стороннего кода из архивов и без публикации настроек камер.

| Источник | Основное содержимое | Ограничения |
|---|---|---|
| `hikvision-demo-ru.zip` | Telegram-бот, `HikvisionClient`, чтение `ISAPI/Event/notification/alertStream`, уведомления и изображения | Демонстрационный проект, нет посещаемости и лицевой идентификации; имеются повторяющиеся определения методов |
| `hikvision-demo-main.zip` | Telegram-бот управления камерами, интеграция с NVR, RTSP-снимки, motion-события | Пользовательские конфигурации камер, пароли могут храниться в файлах; нет распознавания людей и журнала посещаемости |
| `hikvision-demo-main (2).zip` | Вариант того же Telegram-бота, NVR-операции, таблицы конфигураций/результатов смены паролей, XML-бэкапы | Содержит данные конфигурации и потенциально действующие секреты; не подходит для прямого включения в распространяемый продукт |

Решение: написать самостоятельный прототип с отдельными ingest/API ключами, отчётами, журналом и базовыми тестами. Оригинальные `.env`, CSV, XML-бэкапы, IP-адреса, токены, пароли, виртуальные окружения и сторонние зависимости в архив поставки НЕ включены.

**Предупреждение по секретам:** пароли камер и Telegram токены из архива могут быть чувствительными; смените действующие секреты, если архив уже отправляли третьим лицам.

Подтверждённая посещаемость не может формироваться только по кадру движения. Прототип принимает идентификаторы лишь из явно отмеченных успешных событий устройств контроля доступа или при ручной проверке на следующем этапе.
